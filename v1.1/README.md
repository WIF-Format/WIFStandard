# WIF 1.1

**Status:** current standard, unchanged since 1997 · **Format:** INI text · **Extension:** `.wif`

WIF 1.1 is the version every weaving program reads and writes today. Start with the guide if
you want to understand the format; use the specification when you are writing code.

| File | What it is |
| --- | --- |
| [Guide](wif-format_v1_1_guide.md) | Plain-language walkthrough of every section: what it means at the loom, then how it is encoded. Includes notes for implementers and the obsolete parts of the format. |
| [Specification](wif-format_v1_1.md) | Reference tables: every section and key, with type and notes. |
| [`twill-color-and-weave.wif`](twill-color-and-weave.wif) | A complete file: a 2-2 twill on 4 shafts in alternating dark and light. |
